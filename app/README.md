# Viva la Resistance — Android app

Flutter UI + `flutter_singbox_client` (sing-box core) для выборочного
проксирования YouTube и Instagram.

Инструкции по настройке и сборке — в [корневом README](../README.md).

```bash
cp assets/config.example.json assets/config.local.json
flutter pub get
flutter build apk --release
```
